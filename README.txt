EXORCISM EMERGENCY NETWORK — VS CODE PROJECT

FILES
- index.html : website structure
- style.css  : design, layout, animations and responsive styling
- script.js  : interactions, filters, live clock, report demo and sound toggle

RUN ON MAC / VS CODE
1. Extract this ZIP.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted Exorcism_Network_VSCode folder.
5. Open index.html.
6. Right-click in the editor and choose "Open with Live Server".
   If Live Server is not installed, install the "Live Server" extension by Ritwick Dey.
   Alternatively, double-click index.html in Finder to open it in your browser.

NOTES

ORIGINAL AMBIENT SOUNDTRACK
Use the "Ambient off/on" control in the header. The soundtrack is generated with Web Audio
API oscillators (an original atmospheric drone), so there is no external music file. Browsers
require a user click before audio can start. The alliance replay button plays an original
three-note confirmation motif. This is not a recording of an existing song.

SOUND
An original Halloween-inspired ambience is generated by the browser using Web Audio:
a low eerie drone and distant bell-like notes. The page attempts to start it on load.
Important: Chrome and other browsers commonly block audible autoplay until the first click,
tap, or key press. The first interaction unlocks the ambience automatically; the header
sound control can also turn it on or off.
